# Brewbutler UI 设计规范 v2.0.2 · Liquid Glass

> 版本 2.0.2 · 2026-11-08 · 取代 v1.x（暖色不透明卡片 + 铜色强调）· 已与 [UX 优化方案 v1.4](ux-optimization-plan.md) 的 O-01 – O-12 同步
> 对齐文档：[产品方案 PRD](product-plan.md)（功能范围）、[技术基线](technical-notes.md)（brew 7.0.10 实测能力）
> 交付：本规范 + 可交互原型 [ui-mockup.html](ui-mockup.html) + [截图](screenshots/)
> 目标平台：macOS 27+（SDK MacOSX27.2 已实测可用下文 §9 列出的全部 Liquid Glass API）

## 0. 结论先行

v2.0 不再改良 v1 的界面，而是按 macOS 27 的 Liquid Glass 语言从零设计。三个核心取舍：

1. **玻璃只给「控制层」，内容永远实底。** 侧边栏、工具栏、搜索、浮动操作栏、任务岛、检查器、命令面板、弹层用 Liquid Glass；包列表、日志正文、表单内容不上玻璃。长列表的可读性优先于材质炫技。
2. **跟随系统，不再自带品牌色。** 强调色 = 用户的系统强调色（`Color.accentColor`）；表面 = 系统材质与 `windowBackground`；只保留语义色（成功 / 警告 / 危险 / 严重度）。App 的辨识度来自图标、信息结构与安全语义，而不是铜色。
3. **信息架构从 7 项收敛为 5 项。** 概览 / 更新 / 资料库 / 服务 / 维护；「发现」并入工具栏全局搜索；「设置」回到原生 Settings 窗口（⌘,）；底部日志抽屉 + toast + 状态栏合并为一个浮动的**任务岛**。

不变的东西：所有功能、所有安全约束（AGENTS.md §5）、状态词表、漏洞「本次扫描未发现 + 覆盖率」口径、危险动作二次确认。

> 原型与截图中的包版本、CVE、cask、服务记录均为演示数据，事实口径见 technical-notes §1。

## 1. 设计原则

| # | 原则 | 落地 |
|---|---|---|
| G1 | **材质分层** | 内容层（实底）→ 控制层（玻璃）→ 瞬时层（弹层/面板，玻璃 + 阴影）。同一屏最多三层，玻璃不叠玻璃（叠放时用 `GlassEffectContainer` 合并） |
| G2 | **系统优先** | 能用系统控件就不用自绘：`NavigationSplitView` 浮动侧边栏、`.searchable` 工具栏搜索、`Table`、`Form(.grouped)`、`.inspector`、`Settings` scene、`ContentUnavailableView` |
| G3 | **一屏一个主操作** | 主操作 `.glassProminent`（系统强调色 tint）；其余 `.glass`；危险色只出现在确认弹层内 |
| G4 | **形状同心** | 所有嵌套圆角用 `ConcentricRectangle` / `containerShape` 与外层同心；控件优先胶囊形 |
| G5 | **运动有意义** | 玻璃元素之间的形变（任务岛展开、浮动栏出现）用 `glassEffectID` morph；内容切换只淡入淡出 |
| G6 | **安全可解释** | 严重度 + CVE + 修复可用性 + 覆盖率四件套；任何位置都不写「无漏洞」 |
| G7 | **失败可诊断** | 任务岛展开即见进度、退出码、原始日志；失败不自动重试、不自动回滚 |
| G8 | **可访问性先于材质** | 降低透明度 / 提高对比度 / 减少动态效果三套系统偏好全部有对应降级（§1.1） |

### 1.1 材质等级与降级

| 等级 | 触发 | 表现 |
|---|---|---|
| **L0 Liquid Glass**（默认） | macOS 27 默认设置 | 控制层 `glassEffect(.regular)`；浮在彩色内容上的小控件可用 `.clear`；hero 区 `backgroundExtensionEffect()` 延伸到侧边栏下方 |
| **L1 降低透明度** | `accessibilityReduceTransparency` | 系统自动把玻璃变为不透明；自绘玻璃面板额外改用 `windowBackgroundColor` 实底 + 1pt `separator` 描边 |
| **L2 提高对比度** | `colorSchemeContrast == .increased` | 玻璃描边加粗到 1.5pt；次级文字从 `.tertiary` 提升到 `.secondary`；徽章填充不透明度 0.15 → 0.25 |
| **L3 减少动态效果** | `accessibilityReduceMotion` | 关闭 glass morph 与弹性动画，改为 0.15s 交叉淡入；扫描/运行脉冲静止 |

### 1.2 不上玻璃的地方（明确禁止）

- 包列表 / `Table` 行、日志控制台正文、表单输入区、CVE 详情正文。
- 玻璃上再放玻璃卡片（例如检查器里不再套玻璃卡，改用分组 `Section`）。
- 用玻璃做纯装饰（无交互的大面积玻璃色块）。

## 2. 设计 tokens

全部 token 由 `Brewbutler/Design/AppTheme.swift` 提供；视图不得硬编码色值（AGENTS §5.11）。

### 2.1 颜色

**表面与文字——全部系统语义色，不定义十六进制值**

| token | SwiftUI | 用途 |
|---|---|---|
| `canvas` | `Color(nsColor: .windowBackgroundColor)` | 内容区底 |
| `raised` | `Color(nsColor: .controlBackgroundColor)` | 内容卡片、表格 |
| `separator` | `Color(nsColor: .separatorColor)` | 发丝线 |
| `text1/2/3` | `.primary` / `.secondary` / `.tertiary` | 主文字 / 次级 / 元信息（L2 时 text3 → `.secondary`） |
| `accent` | `Color.accentColor` | 选中、链接、主按钮 tint、可更新的新版本号 |
| `glassTint` | `accent.opacity(0.0)` 默认不着色 | 仅主操作与选中 scope 使用 accent tint |

**语义色——系统色，保证随浅深色与对比度设置自动调整**

| token | SwiftUI | 用途 |
|---|---|---|
| `success` | `.green` | 运行中、已是最新、修复可用、任务成功 |
| `warning` | `.orange` | 部分覆盖、doctor 提示、扫描过期（>24h） |
| `danger` | `.red` | 失败、异常、卸载确认 |
| `info` | `.blue` | 离线缓存提示、说明性 callout |
| `neutral` | `.gray` | 已停止、已锁定 |

**漏洞严重度**

| 级别 | 标签 | 颜色 | 符号 |
|---|---|---|---|
| critical | 严重 | `.red` | `exclamationmark.octagon.fill` |
| high | 高危 | `.orange` | `exclamationmark.triangle.fill` |
| medium | 中危 | `.yellow`（文字用 `.primary`，避免黄字低对比） | `exclamationmark.circle.fill` |
| low | 低危 | `.gray` | `info.circle.fill` |
| unknown | 扫描未知 | `.secondary` | `questionmark.circle` |

徽章写法：胶囊 + 颜色 `opacity(0.15)` 填充（L2 为 0.25）+ 同色符号 + `.primary` 文字。**状态永远是「符号 + 文字 + 颜色」三重编码。**

### 2.2 字体

只用系统文本样式，自动支持动态字体。

| 层级 | 样式 | 场景 |
|---|---|---|
| Hero | `.largeTitle.weight(.bold)` | 页面标题（概览、更新…） |
| Title | `.title2.weight(.semibold)` | 包详情标题、弹层标题 |
| Section | `.title3.weight(.semibold)` | 卡片 / 分组标题 |
| Headline | `.headline` | 列表包名、指标数字标签 |
| Body | `.body` | 正文 |
| Callout | `.callout` | 次级信息、表格单元格 |
| Caption | `.caption` | 徽章、时间戳 |
| Metric | `.system(.title, design: .rounded).weight(.semibold).monospacedDigit()` | 指标大数字 |
| Mono | `.system(.callout, design: .monospaced)` | 版本、路径、命令、日志 |

数字一律 `monospacedDigit()`。

### 2.3 间距、尺寸、圆角

- 4pt 网格：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。
- 页面边距：水平 28、顶部 12（hero 下）、底部 = 任务岛高度 + 16（`safeAreaBar` 自动让位）。
- 控件高度：系统 `.regular`（28）；浮动栏与任务岛折叠态 44；scope 分段 32。
- 圆角：窗口由系统决定；内容卡片 18；玻璃面板 24；胶囊控件 `Capsule`；嵌套元素一律 `ConcentricRectangle`（不手写内层半径）。
- 列表行：`Table` 系统行高（单行 24 / 双行内容约 40）；安全更新行双行。

### 2.4 动效

| 场景 | SwiftUI | 减少动态效果时 |
|---|---|---|
| hover / 按压 | `Glass.interactive()` 自带 | 保持（系统处理） |
| 任务岛展开/收起、浮动栏出现 | `glassEffectID` + `.spring(duration: 0.35, bounce: 0.15)` | `.easeInOut(0.15)` 淡入 |
| scope 切换选中胶囊 | `glassEffectID` 滑动 | 直接切换 |
| 页面切换 | 系统默认 | 系统默认 |
| 扫描 / 运行指示 | `symbolEffect(.pulse)` | 静止符号 |

## 3. 窗口、导航与键盘

### 3.1 窗口结构

```
默认 1280×820 pt，最小 980×640
┌─────────────────────────────────────────────────────────────────────────┐
│ ●●●  ╭侧边栏(玻璃,浮动)╮   ‹ ›  更新            ╭🔍 搜索包或命令…╮ ╭↻ ⛨╮ ╭◧╮ │ ← 玻璃工具栏
│      │ ▣ 概览        │ ┌───────────────────────────────────────────┐      │
│      │ ⬇ 更新     36 │ │ hero（backgroundExtensionEffect 延伸到    │      │
│      │ ▤ 资料库   59 │ │        侧边栏下方）                        │      │
│      │ ⚙ 服务    3/4 │ ├───────────────────────────────────────────┤      │
│      │ 🔧 维护        │ │ 内容（实底，滚动边缘 .soft）               │      │
│      │               │ │                                           │      │
│      │╭─────────────╮│ │        ╭── 任务岛（玻璃胶囊）──╮          │      │
│      ││Homebrew 7.0 ││ │        │ ◐ 更新 ffmpeg · 2/6 ▸ │          │      │
│      │╰─────────────╯│ └────────╰───────────────────────╯──────────┘      │
│      ╰───────────────╯                                                    │
└─────────────────────────────────────────────────────────────────────────┘
```

- 侧边栏：`NavigationSplitView` 系统浮动玻璃侧边栏，宽 220（200–260）；底部 `safeAreaInset` 放 Homebrew 状态小卡（版本 · 前缀 · 只读标记）。
- 工具栏三组（`ToolbarSpacer(.fixed)` 分隔，每组一个共享玻璃背景）：①导航（返回）②搜索框（`.searchable(placement: .toolbar)`）③页面动作（刷新 / 扫描）④检查器开关（仅详情页）。外观切换不再放工具栏（跟随系统，可在设置中覆盖）。
- 任务岛：内容列底部居中，`safeAreaBar(edge: .bottom)`；空闲且无 toast 时完全隐藏。
- 检查器：包详情页右侧 `.inspector`，宽 300（280–340），系统玻璃。

### 3.2 信息架构

| 一级 | 快捷键 | 侧边栏徽标 | 来自 v1 |
|---|---|---|---|
| 概览 | ⌘1 | — | 仪表盘 |
| 更新 | ⌘2 | 可更新数（有安全更新时徽标为红） | 更新 |
| 资料库 | ⌘3 | 已安装数 | 已安装 |
| 服务 | ⌘4 | 运行中/总数（有异常时红点） | 服务 |
| 维护 | ⌘5 | doctor 提示数 | 维护 |
| 发现 | 无侧边栏项；工具栏搜索 → 「在 Homebrew 中搜索 “xxx”」 | — | 发现 |
| 设置 | ⌘,（独立 Settings 窗口） | — | 设置页 |

二级：包详情（从任何列表、搜索、命令面板进入，push 到内容列；⌘[ 返回）。

### 3.3 搜索的两层

1. **工具栏搜索（⌘F）**：输入即过滤当前页（更新 / 资料库 / 服务）；建议下拉第一行固定为「在 Homebrew 中搜索 “query”」，回车或点击进入发现结果页（调用 `searchDiscover`）。在概览 / 维护页输入时只显示建议（已安装包 + 远端搜索入口）。
2. **命令面板（⌘K）**：页面 / 包 / 操作三组，玻璃浮层（§4.9）。

### 3.4 快捷键

| 键 | 动作 |
|---|---|
| ⌘1–⌘5 | 一级导航 |
| ⌘F | 聚焦工具栏搜索 |
| ⌘K | 命令面板 |
| ⌘, | 设置窗口 |
| ⌘R | 检查更新（先同步 Homebrew 索引，再检查可更新项；见 technical-notes §2.1） |
| ⇧⌘V | 运行安全扫描 |
| ⇧⌘D | 运行 brew doctor |
| ⇧⌘K | 清理…（进入确认） |
| ⌥⌘L | 展开 / 收起任务岛 |
| ⌘[ | 详情返回 |
| ⌘. | 取消当前任务（任务岛展开时） |
| Esc | 关闭浮层 / 收起任务岛 / 清空搜索 |

从 v1 升级后首次启动给一次性提示「快捷键已调整：⌘2 现在是更新，⌘3 是资料库」（UX 方案 O-05），之后不再出现。

## 4. 页面设计

每页：结构 → 主/次操作 → 状态 → 空态 → 无障碍。

### 4.1 概览（⌘1）

```
┌ hero（延伸到侧边栏下）──────────────────────────────────────────────┐
│ 概览                                           ╭检查更新╮ ╭全部更新 36╮ │
│ 11月7日 周六 · 上游同步于 8 分钟前                                     │
│ ╭────────╮ ╭────────╮ ╭────────╮ ╭────────╮                         │
│ │ ◔ 36   │ │ ◕ 6    │ │ ◑ 1.3GB│ │ ● 3/4  │  ← 4 个指标环（可点击） │
│ │ 可更新  │ │有已知漏洞│ │ 占用    │ │ 服务   │                         │
│ ╰────────╯ ╰────────╯ ╰────────╯ ╰────────╯                         │
└────────────────────────────────────────────────────────────────────┘
┌ 安全 ─────────────────────────────── 部分覆盖 · 36/59 · 18 分钟前 [重新扫描] ┐
│ ▇▇▆▆▅▅▃  严重 1 · 高危 2 · 中危 2 · 低危 1        已有修复 5 · 暂无修复 1   │
│ (openssl@3 严重) (node 高危) (git 高危) (python@3.13 中危) …                │
│ › 为什么是部分覆盖：7 cask 无 OSV 映射 · 11 第三方 tap · 5 缺元数据          │
└──────────────────────────────────────────────────────────────────────────┘
┌ 最近任务 ────────────────────┐ ┌ 健康 ──────────────────────────┐
│ ✓ 更新 ffmpeg   2 分钟前 14s │ │ doctor 2 条提示 › │ missing 正常   │
│ ✕ 更新 node     失败 退出码 1 │ │ 可回收 485 MB ›  │ 孤立依赖 3 个 › │
└──────────────────────────────┘ └────────────────────────────────┘
```

- **指标环**：内容层卡片（实底 18 圆角），环颜色语义化；点击跳转对应页 / 筛选。磁盘环 = Cellar+缓存+Caskroom 占比。
- **主操作**：全部更新（`.glassProminent`，数量在按钮内）；次：检查更新、重新扫描。页面跳转只靠侧边栏、⌘1–⌘5 和指标环，概览不再放「发现 / 服务 / 维护」快捷按钮（UX 方案 O-05）。
- **扫描可能已过时**（UX 方案 O-07）：上次扫描之后已安装快照有变化（快照哈希不一致）时，安全卡标题下显示 warning 条「已安装的包有变化，扫描结果可能已过时。」，用户用标题行的「重新扫描」确认；不自动扫描。更新页覆盖率行同样显示。
- **状态**：首次未扫描 → 安全卡显示「尚未扫描。全量扫描约需 30 秒。[开始扫描]」；扫描中 → 卡内进度 + 「已检查 24/36 个 formula · 已用 12 秒」 + 取消；扫描失败 → 「扫描未知」+ 原因 + 重试；扫描 >24h → 时间变 warning 色。
- **空态**：「环境健康，没有需要处理的事项。」（仅当无更新、doctor 通过；安全卡仍按覆盖率口径单独陈述）。
- **无障碍**：指标环 `accessibilityLabel("可更新 36 个包")` + 按钮 trait；严重度分布条合并朗读「严重 1，高危 2…」。

### 4.2 更新（⌘2）

```
更新                                     ╭预览╮ ╭全部更新 36╮ ← 主按钮随 scope 变化
36 个可用更新 · 5 个安全更新 · 上游同步于 8 分钟前 · 本机检查于 2 分钟前
╭ 全部 36 │ 安全 5 │ formula 32 │ cask 4 ╮   ← 玻璃 scope 栏（GlassEffectContainer）
─ 安全更新 · 部分覆盖 36/59 ─────────────────────────────────────────────
□ ⛔ openssl@3   严重 · CVE-2025-9230 · 修复于 3.6.1    3.6.0 → 3.6.1  [更新]
□ ⚠ node         高危 · CVE-2025-27210                 24.9.0 → 24.9.1 [更新]
─ 常规更新 ──────────────────────────────────────────────────────────────
◐ ffmpeg        正在下载…  ▒▒▒▒▒▒▒                      7.1 → 7.1.1
✓ librsvg       完成 14s                                2.63.3 → 2.63.4
✕ aom           失败 · 退出码 1 · Error: …（首行）  [查看日志] [重试…]
□ jq                                                   1.7.1 → 1.8.1    [更新]
          ╭ 已选 3 项   更新所选   预览   取消选择 ╮   ← 浮动玻璃操作栏（有选中才出现）
```

- **一个主按钮，随范围变化**（UX 方案 O-04）：页头只有一个主按钮，没有独立的「更新安全项」按钮。所有路径都先进入批量更新确认（§4.10）。

  | 状态 | 页头主按钮 |
  |---|---|
  | scope = 全部，未选择 | 全部更新 36 |
  | scope = 安全 | 更新 5 个安全项 |
  | scope = formula / cask | 更新 32 个 formula / 更新 4 个 cask |
  | 有选中项 | 页头主按钮降为普通玻璃按钮，浮动操作栏「更新所选」是唯一主操作 |

- **贪婪模式**不在页头：移到 设置 → Homebrew（§4.11）；开启时副标题末尾加徽章「含自动更新的 cask」，点击打开设置。
- **行内操作**：只保留「更新」；dry-run 预览放在行的 hover 操作与右键菜单（VoiceOver 用 `accessibilityAction` 暴露）。
- **单列表承载完整流程**：待更新 / 排队 / 运行（不定态条 + 阶段）/ 完成 / 失败都在行内，状态圆点替代复选框；不另设「已完成」分组。
- **安全分组置顶**，按严重度排序；分组头常驻覆盖率；暂无修复的漏洞行写「上游暂无修复版本」，不给假按钮。
- **浮动操作栏**：选中 ≥1 时从任务岛位置上方 morph 出现（`glassEffectID`），与任务岛同属一个 `GlassEffectContainer`；内容：计数 + 主操作「更新所选」+ 预览 + 取消选择。
- **已锁定**：行内「已锁定」徽章，复选框禁用并 tooltip「已锁定的包不会被更新，可在详情中解锁」。
- **空态**：「所有包都是最新版本。」+ 检查更新；筛选无结果 → 「当前筛选没有结果。」+ 清除筛选。
- **检查更新**：先在任务岛显示「正在同步 Homebrew 索引…」（作为队列任务，正在执行的变更之后才开始），再刷新列表；同步失败不阻断。
- **离线 / 缓存**：顶部内联提示（玻璃 notice）「需要网络，当前显示 2 小时前的缓存。[重试]」；同步失败但本地检查成功时为「未能同步上游，结果基于 2 小时前的本地索引。[重试]」。

### 4.8 任务岛（取代日志抽屉、toast、状态栏）

**折叠态**（44pt 胶囊，最大宽 520）：

```
╭ ◐ 更新 ffmpeg · 2/6 · 已用 01:24        ⏸  ✕  ⌃ ╮
```

- 运行中：脉冲符号 + 当前任务 + 批次计数 + 已用时间 + 暂停 / 取消 + 展开。
- **任务开始时不自动展开**：只以折叠态出现（`glassEffectID` morph 进场）；展开只由用户触发（点击、⌥⌘L、「查看日志」）。
- 空闲且最近一次任务 <5 分钟：显示结果 1 行（✓ 成功 / ✕ 失败 · 退出码），5 秒后淡出；失败结果常驻到用户查看。
- **批次结果态**（取代 v1 的批次汇总 sheet）：`✓ 6 个包已处理 · 1 个失败 ›`；全部成功时 5 秒后淡出，有失败、未验证或已取消时常驻。点击后展开为「汇总」视图：成功 / 失败 / 未验证 / 已取消计数、失败包的退出码与首行错误、[查看日志] [重试…]，以及次操作「重新扫描」（UX 方案 O-07）。失败 toast 不再单独出现，由结果态承载。
- **系统通知**：任务完成通知只在 App 不在前台时发送（仍受设置 → 通知开关控制）；点击通知回到主窗口并展开对应结果。
- Toast：作为岛左侧的小胶囊出现（同一 `GlassEffectContainer`，靠近时自动融合），2.6s 消失；可点击打开对应任务。

**展开态**（玻璃面板 宽 min(内容宽-56, 760) × 高 360，`glassEffectID` morph）：

```

│ ▓▓▓▓▓▓▓░░░░░░░░░░  进度只按实际完成数推进                                 │
│ ╭ 进度 │ 日志 │ 队列 3 │ 历史 ╮                                             │
│ ✓ librsvg  完成 14s                                                       │
│ ◐ ffmpeg   正在下载…                                                       │
│ ✕ aom      失败 · 退出码 1 · Error: …   [复制] [重试…]                     │
│ ○ jq       排队中                                                          │
╰──────────────────────────────────────────────────────────────────────────╯
```

- 「日志」tab 内是**实底**控制台（`textBackgroundColor`，SF Mono，自动跟随，可复制、可打开日志文件）——玻璃面板里唯一的实底区域。
- 「队列」：待执行任务，可单个移除；「历史」：最近记录，可打开日志、复制命令、重试（需确认）。
- 更新页可见时，逐包行已在主列表，展开态「进度」tab 只显示批次总进度（避免同一批次行出现两份）。
- Esc / ⌥⌘L 收起；任务结束不自动收起（用户在看时）。

### 4.10 确认弹层

系统 `.sheet`（macOS 27 自带玻璃边框），宽 440，结构：符号 → 标题（即后果）→ 影响说明 → 输入确认（如需）→ 「取消」（默认焦点）+ 危险按钮（`.glass` + `.tint(.red)`）。

| 弹层 | 标题示例 | 特殊规则 |

### 4.13 菜单栏

- **正在检测 Homebrew**：居中 `ProgressView` + 「正在检测 Homebrew…」。

## 7. 无障碍

- **对比度**：玻璃上的文字由系统 vibrancy 保证；自绘玻璃面板内文字只用 `.primary` / `.secondary`。正文 ≥4.5:1；L2 提高对比度时自动加强。
- **不只靠颜色**：所有状态「符号 + 文字 + 颜色」。
- **焦点**：系统焦点环（跟随强调色）；自绘行使用 `.focusable()` + 系统焦点效果；弹层与命令面板焦点陷阱，Esc 关闭。
- **VoiceOver**：行朗读「openssl@3，formula，有已知漏洞 严重，可更新到 3.6.1」；任务岛为 `accessibilityElement(children: .contain)`，状态变化 `AccessibilityNotification.Announcement`；指标环为按钮。
- **动态字体**：只用文本样式；关键行 `minimumScaleFactor(0.85)`。
- **系统偏好**：§1.1 L1–L3 全部实现并在走查中逐一验证。
- **键盘**：全部功能可达；危险确认默认焦点「取消」。

## 8. 安全体验设计

`brew vulns --json` 实测语义决定 UI 形状：覆盖不完整（本机 36/59、23 包跳过、`complete=false`）、约 30 秒、发现漏洞时退出码可能为 1；**不自动全量扫描**。

1. **安全卡（概览）**：分布条 + 受影响包 chip + 修复可用性 + 覆盖率 + 跳过原因 + 「退出码 1 属预期」说明。
2. **扫描态**：卡内进度 + 「已检查 X/Y 个 formula · 已用 N 秒」+ 取消；取消后保留上次结果；扫描只手动触发。
3. **更新页**：安全分组置顶、按严重度排序，分组头常驻覆盖率。
4. **修复可用性**：有修复 → 引导更新；无修复 → 「上游暂无修复版本」，不提供假按钮。
5. **详情安全 tab**：CVE、摘要、严重度、影响版本、修复版本、来源、本次扫描说明；检查器健康区做摘要。（CVSS 无数据源，不显示。）
6. **诚实边界**：任何位置都不写「无漏洞」，只写「本次扫描未发现」+ 覆盖率 + 扫描时间；扫描失败显示「扫描未知」。
